# RoRo v3 Tappa 1: spazio perso, navi, export e link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aggiungere spazio perso in %, navi predefinite, export PDF e CSV, link condivisibili per Reveal e Lab.

**Architecture:** L'engine riceve due novità con valori di default che riproducono la v2: `broken_stowage_pct` sulla nave e costanti di stabilità impostabili da `ScenarioParams`. Il server aggiunge le navi predefinite, i nuovi campi del Lab e un'unica API di export. Il browser codifica partita o impostazioni del Lab nella parte `#` dell'URL, quindi il server non salva nulla.

**Tech Stack:** come la tappa 0, più ReportLab per il PDF.

**Spec:** `docs/superpowers/specs/2026-11-06-roro-v3-design.md` (§7 link, §9.4 spazio perso, §9.6 navi, §9.9 PDF, §11 tappa 1)

## Global Constraints

- Branch di lavoro `v3-stage-1`. **Nessun push su `v3` prima dell'ok del proprietario**: il trigger Cloud Run pubblica ogni push su `v3`.
- Con tutti i nuovi parametri ai valori di default, i risultati dell'engine sono identici a prima su seed fissi.
- Il gioco resta con spazio perso 0 e la nave demo 5 × 120 m.
- Navi predefinite: valori arrotondati scritti da noi, mai navi con nome; il testo dice "Typical rounded figures, not a named ship".
- Testo PDF obbligatorio: `Planning estimate, not a loading computer.` e `Synthetic data, not DFDS data.`
- Link: massimo 4.000 caratteri dopo `#`; un link non valido mostra un messaggio e non rompe la pagina.
- Un link condiviso non sovrascrive la partita salvata da chi lo apre.
- Cloud Run: 1 vCPU, una sola istanza; un calcolo lungo deve mostrare un avviso prima di partire.

## Review Focus

- Nave grande (16 corsie, 190 richieste) con il piano smart: l'utente vede prima l'avviso sul tempo, poi l'avanzamento e il pulsante per annullare. Test in Task 4.
- Link modificato a mano o troncato: messaggio "This link is damaged or incomplete." e pagina utilizzabile. Test in Task 5.
- Export richiesto prima che il piano esista (smart o best non pronti): 409 con motivo leggibile, pulsante disattivato finché il piano manca. Test in Task 3 e Task 5.
- Spazio perso al 30% su una nave piccola con unità lunghe: nessun crash; le unità che non entrano più in una zona sono spiegate. Test in Task 1.
- Link condiviso aperto da chi ha una partita in corso: la sua partita resta salvata. Test in Task 5.

@pytest.mark.parametrize("key", ["ropax", "shortsea"])
def test_large_presets_load_most_of_the_demand(client, key, wait):
    values = {**client.get("/api/lab/defaults").json()["values"], **PRESETS[key]["values"]}
    plans = wait(client, client.post("/api/lab/plans", json=values).json()["job_id"], timeout=120)["result"]

def test_every_preset_value_is_inside_the_limits():

### Task 3: API di export PDF e CSV

**Files:**
- Create: `server/exports.py`, `server/export_api.py`
- Modify: `server/lab_api.py` (sposta la scelta del piano in `resolve_lab_plan`), `server/main.py`, `requirements.txt` (`reportlab>=4`)
- Test: `tests/api/test_exports.py`

**Interfaces:**
- Produces: `ExportRequest{source: "lab"|"game", params: LabParams|None, seed: int|None, decisions: list[Decision], plan_key: "fcfs"|"optimal"|"smart"|"you"|"best"}`; combinazioni valide: lab con fcfs, optimal o smart; game con you, fcfs, smart o best. Altre combinazioni: 422.
- Produces: `resolve_lab_plan(params, plan_key) -> tuple[Scenario, Plan] | None` e `resolve_game_plan(seed, decisions, plan_key) -> tuple[Scenario, Plan] | None`. `None` significa piano non ancora calcolato. Per il gioco, smart e best si leggono dai job `("smart", seed, ADVISOR_K)` e `("best", seed, decisions_key(decisions))`.
- Produces: `plan_pdf(scenario: Scenario, plan: Plan, title: str, assumptions: list[str]) -> bytes`: titolo, nave e rotta, KPI di `evaluate`, disegno del ponte (rettangoli per corsia e unità, colori contract e spot), tabella del manifest, ipotesi, le due frasi obbligatorie.
- Produces: `POST /api/export/pdf` e `POST /api/export/csv`; 409 con `detail = "This plan is not ready yet. Wait for it, then download."`. `/api/manifest.csv` resta come alias del CSV del Lab.
